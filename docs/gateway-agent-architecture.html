Jarvis Gateway Target Architecture

Gateway control plane + intelligent provider routing + two-layer agent loop

Gateway = control plane

Web surfaces and future channels share authentication, routing, sessions, configuration and an append-only run event stream. The Gateway coordinates runs but does not implement model protocols or tools.

Two-layer agent loop

The outer loop owns task lifecycle and follow-ups. The inner loop repeatedly selects a route, streams a model response, executes tools and feeds observations back until the turn settles.

Safe provider switching

Capabilities and policy filter candidates first; health, latency, cost and load rank them. Automatic replay stops at side-effect boundaries, and every attempt is persisted for audit.
